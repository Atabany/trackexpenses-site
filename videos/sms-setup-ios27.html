Full video transcript

0:00 · Start in the Library

Open Shortcuts. Go back to Library, then choose Automation.

0:06 · Create a new shortcut

Tap the + at the bottom. In iOS 27, automations live inside shortcuts.

0:12 · Open the editor

If Describe a Shortcut opens, tap Editor or Edit. Then tap Automation in the actions panel.

0:20 · Choose Message

Under Communication, tap Message to add the incoming-message trigger.

0:26 · Change the filter field

Tap the first blue Sender field. This chooses what part of the message to match.

0:33 · Match the message text

Choose Message from the menu. The condition becomes Message contains Text.

0:39 · Use your bank’s wording

Tap Text and enter wording from your bank alerts. Purchase is only an example. Then tap the trigger’s blue arrow.

0:47 · Let it run automatically

Keep Automation on and Confirm Before Run off. These replace the older Run Immediately screen.

0:55 · Find the import action

Tap Search, type Import Bank Message, then select the TrackExpenses action.

1:01 · Connect the incoming text

Tap the blue Message placeholder inside Import transaction from Message.

1:07 · Open Select Variable

Tap Select Variable in the bottom bar. Do not type a message or use Ask Each Time.

1:14 · Choose the trigger’s Message

Tap Message directly below the trigger. In iOS 27 this is the incoming message output.

1:22 · Use the message body

Close the bottom bar with ×. Tap the inserted Message variable to see its properties.

1:29 · Choose Content

In the variable’s Get list, choose Content. Tap Return, then close the variable bar with ×.

1:37 · Keep imports quiet

Expand the import action’s blue arrow and turn Show When Run off. The connected variable should say Content.

1:45 · Check the shortcut’s privacy

Tap the ⓘ button in the editor toolbar, then open Privacy.

1:51 · Allow it while locked

Keep Allow Running When Locked enabled. Go back to Details, tap Done, then back to save the shortcut.

1:59 · Ready for your next bank alert

Confirm the automation is enabled. Check the next matching alert in TrackExpenses → More → SMS Auto-Import.

App facts and free / Pro limits

Expense Tracker: SMS & Voice (TrackExpenses) is made by Mohamed Elatabany for iPhone and iPad with iOS/iPadOS 17 or later. The app is in English and Arabic, with a full right-to-left Arabic interface. No app account or bank login is required. Optional Shortcuts automations import supported bank SMS and Wallet purchases; the app does not read your Messages inbox. Voice entry creates on-device drafts on compatible devices and languages. The free ledger includes unlimited manual transactions, budgets, historical stats, search, monthly CSV export, private iCloud sync, 3 accounts, 2 recurring rules, 10 saved voice entries per calendar month per device and 10 successful automatic bank SMS imports per calendar month per device. SMS alerts past the free allowance are kept but locked outside totals; upgrading to Pro adds them all, otherwise the next calendar month’s allowance releases as many as it covers. Nothing is dropped and saved history is never locked. Pro adds unlimited voice entry, SMS imports, accounts and recurring rules, forecasts, daily budget guidance, what-if planning, CSV import, date-range CSV exports, full JSON backup and restore, themes and alternate icons. Monthly and annual subscriptions and a one-time lifetime purchase are available. Spending calculations depend on your records and are not financial advice.
